Приватность

Вы решаете, кто видит ваш номер, фото и статус. История хранится на вашем телефоне.

Как установить

  1. Нажмите «Скачать для Android» и откройте файл ICQ-New.apk.
  2. Если телефон спросит — разрешите установку из этого источника.
  3. Откройте ICQ New, введите номер телефона — код страны подставится сам.
  4. Для компьютера: откройте веб-версию и отсканируйте QR-код в приложении (Профиль → Веб-версия).
